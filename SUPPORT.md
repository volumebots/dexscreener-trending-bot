# Support

Official DexMoji support: [`@dexmojisupport`](https://t.me/dexmojisupport)

## Information to Prepare

- Blockchain
- Token contract
- Destination platform
- Requested placement or reaction type
- Order reference
- Approximate campaign time
- Public payment transaction hash
- Expected and observed delivery

Never send private keys, seed phrases, login codes, passwords or unrelated personal information.

GitHub Issues are for public documentation corrections. Campaign and payment questions belong in official support.
