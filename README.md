## Selecting the Right Trending Destination

The strongest campaign destination is not automatically the platform with the highest possible position. It is the platform most relevant to the token's network, DEX pair and target audience.

### Start with the blockchain

Verify the network and contract before comparing services. Phantom, Padre, SolScan and RugCheck are listed as Solana-only. DexScreener, DexTools, GMGN and GeckoTerminal support multiple chains subject to current availability.

### Identify the research behavior

Consider where the intended audience already checks token charts, liquidity, holders, swaps and contract information. A placement is more useful when it appears in a tool that potential visitors actually use.

### Check the token profile

Increased visibility sends more people to the destination page. Confirm that the token name, contract, pair, project description, artwork, website and public information are accurate before ordering promotion.

### Align the timing

Trending can support an announcement, product update, community event or other legitimate marketing activity. Avoid ordering a campaign before public pages and communication channels are ready for attention.

## DexScreener Reactions

Trending positions and reactions solve different promotional tasks.

- **Trending** affects visibility within discovery surfaces.
- **Reactions** add selected engagement signals to a DexScreener token page.

DexMoji publishes support for these reaction types:

- 🚀 Rocket
- 🔥 Fire
- 💩 Poop
- 🚩 Red flag
- ⭐ Watchlist

A reaction order should include the correct token page, desired reaction type and current quantity. Record existing totals before delivery so the campaign can be checked afterward.

Paid reactions must not be reported as independent user sentiment. Negative reactions should not be used to target unrelated projects or competitors.

## Building a Campaign Brief

A concise campaign brief helps support verify the order and helps the project review delivery.

Include:

1. Blockchain network
2. Token contract
3. Exact DEX pair or destination page
4. Requested platform
5. Desired placement range or reaction type
6. Intended campaign window
7. Project contact responsible for verification
8. Baseline metrics
9. Delivery metrics to record

Check every contract character before submitting the order. A campaign delivered to the wrong token page cannot support the intended project.

## Interpreting Results Correctly

A DEX Trending Bot can deliver paid visibility. It cannot determine the quality of the token or create a durable community by itself.

Trending does not prove:

- Organic demand
- Token safety
- Contract quality
- Real holder growth
- Sustainable liquidity
- Product-market fit
- Long-term placement
- Future token value

Projects should distinguish three different measurements:

1. **Delivery:** Was the booked placement or reaction package delivered?
2. **Attention:** Did the campaign increase page visits or engagement?
3. **Business impact:** Did qualified visitors continue exploring the project after the promotion?

Only the first measurement is controlled directly by the promotional order.
