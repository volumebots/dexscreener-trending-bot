# Contributing

Contributions should improve the accuracy, accessibility or safety of this DEX Trending Bot repository.

Useful changes include corrected official links, clearer platform coverage, updated published placement information, formatting improvements and terminology fixes.

Product changes should cite a current DexMoji-controlled source. Do not add unsupported guarantees, third-party affiliation claims, token endorsements, credentials or private user information.

Pull requests should explain the correction, identify the source and confirm that links and Markdown were checked.
