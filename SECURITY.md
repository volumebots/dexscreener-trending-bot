# Security Policy

This repository documents the hosted DexMoji DEX Trending Bot and contains no production execution code.

## Reporting

Contact [`@dexmojisupport`](https://t.me/dexmojisupport) regarding impersonation, unsafe links, copied accounts, suspicious payment instructions or service-related security concerns.

Include the target contract, campaign destination, bot username, order reference, approximate time and public payment transaction hash. Remove sensitive data from screenshots.

## Never Provide

- Private keys
- Seed phrases
- Telegram login codes
- Exchange passwords
- Authentication tokens
- Remote device access

## Verify Accounts

Use [dexmoji.com](https://www.dexmoji.com/), [`@dexmojibot`](https://t.me/dexmojibot) and [`@dexmojisupport`](https://t.me/dexmojisupport). Display names and avatars can be copied.
